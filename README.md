# Сайт-візитка перукаря

Статичний сайт (HTML/CSS/JS), без бекенду. Форма запису відкриває чат у Telegram/Viber з готовим повідомленням.

## Що заповнити перед публікацією

1. **`index.html`**
   - Ім'я/назва (`<title>`, `.logo`, розділ "Про мене")
   - Місто, адреса, графік роботи, телефон, Instagram (`#contacts`)
   - Послуги та ціни (`#services`)
   - Фото — заміни блоки `.ph` у `#gallery`, `.about-photo`, `.map` на реальні `<img>`

2. **`script.js`** (на самому верху файлу)
   - `TELEGRAM_USERNAME` — юзернейм Telegram-акаунту дружини (без @)
   - `VIBER_PHONE` — номер телефону для Viber (формат `380XXXXXXXXX`)

3. Додай фото у папку `assets/` і встав `<img src="assets/фото.jpg">` замість заглушок `.ph`.

## Локальний перегляд

```
python3 -m http.server 8080
```
відкрити http://localhost:8080

## Безкоштовний хостинг (варіанти)

- **GitHub Pages** — залити цю папку в репозиторій, увімкнути Pages в налаштуваннях.
- **Netlify / Vercel** — перетягнути папку на сайт сервісу (drag & drop deploy), отримати посилання за хвилину.

Обидва варіанти безкоштовні, без бекенду не потрібні — усе, що є в цій папці, вже готове до деплою "як є".


## Матеріали для нової композиції

- Портрети Валентини й Алли: у `index.html` замінити `.portrait-placeholder` на `<img src="assets/valentina.jpg" alt="Валентина — перукарка" width="600" height="800">` та відповідний портрет Алли.
- У `#about` замінити позначені тексти на розповіді майстринь та їхні спеціалізації.
- У `#gallery` додати фото до/після, запит, рішення, час і вартість кожної роботи. Фото вставляти всередину `.story-photo`; підписи «До» й «Після» залишити.
- Для підтверджених робіт додати `data-master="Валентина"` або `data-master="Алла"` до посилання запису. `data-service` має збігатися з опцією форми.
- У `#reviews` додати справжні відгуки з посиланнями на джерело.
